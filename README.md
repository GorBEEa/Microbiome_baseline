# Microbiome_baseline 🐝 🧬🦠 
Includes data and analysis of data on microbiome composition through time and space of *Bombus pascuorum* individuals captured in Gorbea Natural Park

* Chueca Luis J., Poza Jon, Dhami Manpreet K., Donald Marion L., Gostout Christian, Hermosilla Brais, Rose Jennifer, Salgado-Irazabal Xabier & Magrach Ainhoa. Seasonality and spatial context shape the gut microbiome diversity of the common carder bee *Bombus pascuorum*. *in prep*.

ASVs where obtained following [DADA2_pipeline](https://github.com/GorBEEa/DADA2) repository

## Check for contaminants
* `01_decotam.R`: Remove putative contaminants with [decotam](https://github.com/benjjneb/decontam/tree/master) R package.
